TreeSelect is a component that combines a tree structure with a select dropdown, ideal for hierarchical data selection.

Example

Usage

Tree Select requires an input field to display the selected nodes and trigger the dropdown menu.

HTML Setup

  <div class="input-field">
    <input type="text" id="my-tree-select" placeholder="Select..." readonly>
    <label for="my-tree-select" class="active">Tree Select</label>
  </div>
JavaScript Initialization

  document.addEventListener('DOMContentLoaded', function() {
    var treeData = [
      {
        id: '1', 
        title: 'Node 1', 
        children: [
          { id: '1-1', title: 'Child Node 1' }
        ]
      }
    ];

    var elem = document.getElementById('my-tree-select');
    var instance = M.TreeSelect.init(elem, {
      data: treeData,
      multiple: true,
      onChange: function(selectedNodes) {
        console.log(selectedNodes);
      }
    });
  });

Options

Name Type Default Description
data Array [] Tree structured data. Each node should have id, title, and optionally children.
multiple Boolean false If true, checkboxes will be rendered and multiple selections are allowed.
closeOnSelect Boolean true If true and multiple is false, the dropdown will close upon selecting a leaf node.
onChange Function null Callback fired when selection changes. Receives an array of selected node objects.
