Provide a placeholder while content is loading to improve user experience.

Example

Usage

You can use the skeleton component purely with CSS by adding the skeleton class, or initialize it via JavaScript if you need to destroy it later when content loads.

CSS Setup

Add the skeleton class to any container. Use CSS or inline styles to define dimensions (height, width) and shapes (border-radius).


<!-- Circular Skeleton (Avatar) -->
<div class="skeleton" style="width: 50px; height: 50px; border-radius: 50%;"></div>

<!-- Rectangular Skeleton (Text/Image) -->
<div class="skeleton" style="width: 100%; height: 20px;"></div>
JavaScript Initialization

By initializing through JavaScript, you gain the ability to call the destroy() method when data has finished loading, which removes the skeleton styling.


  <div class="my-skeleton-target" style="width: 100%; height: 20px;"></div>
        

  document.addEventListener('DOMContentLoaded', function() {
    var elems = document.querySelectorAll('.my-skeleton-target');
    var instances = M.Skeleton.init(elems, options);

    // Later, when content has loaded:
    // instances[0].destroy();
  });
