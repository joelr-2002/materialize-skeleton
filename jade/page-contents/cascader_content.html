A Cascade selection box is when you need to select from a set of associated data set. Such as province/city/district.

Example

Usage

Cascader requires an input field to display the selected path and trigger the dropdown menu.

HTML Setup

  <div class="input-field">
    <input type="text" id="my-cascader" placeholder="Select region..." readonly>
    <label for="my-cascader" class="active">Location</label>
  </div>
JavaScript Initialization

  document.addEventListener('DOMContentLoaded', function() {
    var cascaderData = [
      {
        value: 'zhejiang',
        label: 'Zhejiang',
        children: [
          {
            value: 'hangzhou',
            label: 'Hangzhou',
            children: [
              { value: 'xihu', label: 'West Lake' },
              { value: 'shangcheng', label: 'Shangcheng' }
            ]
          }
        ]
      }
    ];

    var elem = document.getElementById('my-cascader');
    var instance = M.Cascader.init(elem, {
      data: cascaderData,
      onChange: function(selectedPath) {
        console.log(selectedPath);
      }
    });
  });

Options

Name Type Default Description
data Array [] Tree structured data. Each node can have value, label, and children.
onChange Function null Callback fired when a leaf node is selected. Receives an array of selected option objects.
