Clickable & JavaScript Initialization

By initializing through JavaScript, you can make Steps clickable and handle the `onChange` event.

  • 1
    Step 1
    This is a content.
  • 2
    Step 2
    This is a content.
  • 3
    Step 3
    This is a content.

  <ul class="steps clickable" id="my-steps">
    ...
  </ul>
        

  document.addEventListener('DOMContentLoaded', function() {
    var elem = document.getElementById('my-steps');
    var instance = M.Steps.init(elem, {
      clickable: true,
      onChange: function(index, stepElement) {
        console.log('Clicked step ' + index);
      }
    });
  });
