Upload component is used to select and upload files or drag and drop files.

Upload by Clicking

Classic mode. File selection dialog pops up when the upload button is clicked.

cloud_upload Click to Upload 

// Basic initialization
let el = document.querySelector('#upload-basic');
let instance = M.Upload.init(el, {
  action: 'https://660d2bd96ddfa2943b33731c.mockapi.io/api/upload',
  name: 'file',
  onChange: function(info) {
    if (info.file.status === 'done') {
      M.toast({html: `${info.file.name} uploaded successfully`});
    } else if (info.file.status === 'error') {
      M.toast({html: `${info.file.name} upload failed`});
    }
  }
});

Drag and Drop

You can drag files to a specific area to upload. Alternatively, you can also upload by selecting.

inbox

Click or drag file to this area to upload


M.Upload.init(document.querySelector('#upload-drag'), {
  action: 'https://660d2bd96ddfa2943b33731c.mockapi.io/api/upload',
  multiple: true,
  drag: true,
  onDrop: function(e) {
    console.log('Dropped files', e.dataTransfer.files);
  }
});
